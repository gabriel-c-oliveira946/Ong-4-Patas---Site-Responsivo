# 🐾 Refúgio Esperança Animal - Landing Page Responsiva

**🌍 Acesso ao site:** [Clique aqui para acessar o projeto online](https://ong-4-patas-site-responsivo-btxj.vercel.app/)

##  Sobre o Projeto
Este projeto é uma página web responsiva desenvolvida para a ONG **Refúgio Esperança Animal**. A atividade teve como foco principal aplicar conceitos de **responsividade** (adaptação para desktop, tablet e mobile) e realizar a **hospedagem** do site. 

Este trabalho prático foi desenvolvido para o curso técnico em **Desenvolvimento de Sistemas** do **SENAI Dendezeiros**.

##  Tecnologias Utilizadas
* **HTML5:** Estruturação semântica da página.
* **CSS3:** Estilização, uso de variáveis (`:root`) e responsividade avançada utilizando `@media queries`. 

##  Funcionalidades e Layout
* **Desktop:** Exibição das imagens alinhadas lado a lado via `inline-block`.
* **Tablet:** Adaptação fluida do layout, ajustando as porcentagens para garantir a organização visual.
* **Mobile:** Reorganização total dos elementos (empilhamento vertical) para navegação intuitiva em telas menores.
* **UI/UX:** Efeitos visuais de `hover` nos cards (zoom, mudança de cor e box-shadow) para melhorar a interatividade.
